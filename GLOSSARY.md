# TodoSort

TodoSort is the shared language for planning work as a living list of action items grouped by context, priority, and timing. It is used as a prioritised reading list most often - the URL attached to an action item is very important.

## Language

**Action item**:
The smallest unit of work in the system: a task that can be ranked, moved between contexts, deferred, or marked complete.
_Avoid_: task, item, entry

**Context**:
A named place in the list that gives an action item a working environment, such as a project lane or a lifecycle state.
_Avoid_: folder, category, bucket

**Project**:
A coherent body of work that can contain related action items and help organize them as a group or sequence.
_Avoid_: initiative, workstream

**Deferred item**:
An action item intentionally postponed until a future date, then automatically returned to active work when that date arrives.
_Avoid_: someday item, parked item

**List state**:
The current arrangement of action items, including the active context, search results, and visible sorting.
_Avoid_: view state, UI state

**File lifecycle**:
The phases through which a TodoSort file moves: opened, tracked, saved, and reloaded as the working copy changes.
_Avoid_: file state, document state
